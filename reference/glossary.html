Glossary

The vocabulary of the week. Lessons, PR reviews and the Friday demo use these words and no others.

ReferenceSource of truth: CONTEXT.mdPrint it; keep it beside you
How to use this page When a word in a lesson, a PR or a stand-up feels fuzzy, look it up here first. Each entry says what the thing is, what it never does, and which words to avoid. If you find yourself needing a word that is not here, that is a question for the Teams channel, not a reason to invent one.

Layers

TermDefinitionNeverAvoid saying
LandingThe zone where source files arrive exactly as delivered: immutable, original format.Read by consumers. Only the bronze load reads it.raw, inbox, staging, source bucket
BronzeThe first Delta layer: every landed row, appended as-is with ingestion metadata (source file, load time). Full history kept.Cleans anything.raw Delta, clean, ingest layer
SilverThe cleaned Delta layer: typed columns, one row per business entity, duplicates resolved by merging on the business key.Drops a row silently: failures go to quarantine.clean, curated, refined
QuarantineA Delta table beside silver holding the rows silver rejected, with the rule that rejected them.Gets forgotten. Read it before you read gold.reject table, dead-letter, error table
GoldThe consumer-facing Delta layer: aggregates and joins shaped for one question.Cleans anything. A fix a gold query needs belongs in silver.mart, reporting layer, serving layer

Movement

TermDefinitionAvoid saying
HopOne transformation from a layer to the next (landing→bronze, bronze→silver, silver→gold). Each hop is one job.step, stage, task
DropOne delivery of source files into your landing. Drops are numbered; each later drop carries defects the earlier ones did not. You receive the next drop when your pipeline handles the current one (drop next), not on a fixed day.batch, load, delivery, ingest
Business keyThe column(s) that identify one real-world entity across drops. Silver merges on it. This week: the barcode code.primary key, id, natural key

Platform

TermDefinitionAvoid saying
BatchA Dataproc Serverless run of one job. Pay per run, no cluster to manage. A batch is immutable: re-running means a new batch_id.cluster job, Spark job, submission

Course

TermDefinitionAvoid saying
Core coreThe part of an exercise every learner completes. The pass criterion depends only on core.mandatory, basic, level 1
Stretch stretchAn optional harder extension for learners who finish core early. Never a prerequisite for a later core exercise.bonus, advanced, level 2, optional

The five layers in one line each

  1. Landing keeps the evidence.
  2. Bronze keeps everything, with a stamp.
  3. Silver keeps one row per thing, and says why it refused the rest.
  4. Quarantine is where "the rest" lives.
  5. Gold answers a question and touches nothing.
