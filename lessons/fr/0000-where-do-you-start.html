≈ 45 minutesPrérequis : aucunRéférence : glossaire (en anglais)
Pourquoi cette leçon D'ici vendredi, tu auras construit un pipeline medallion sur GCP, en grande partie seul : personne dans la salle de mardi à jeudi. Du coup, il te faut deux choses :
  • une idée claire d'où tu pars, pour que les hints et les exercices stretch collent à ton niveau
  • un environnement qui marche à 10h15, pour que la semaine parte dans le pipeline, pas dans Docker

1. Sept critères, trois niveaux core

Évalue-toi. Pas de note, tes réponses servent juste à caler la semaine.

  • Rien : les hints de chaque exercice sont écrits pour toi.
  • Un peu : tu l'as déjà utilisé, mais tu ne saurais pas le faire comprendre à quelqu'un.
  • Solide : tu pourrais l'expliquer à ton voisin, du coup les exercices stretch sont pour toi.

Colle la ligne de résumé dans le canal Teams. Le formateur se sert des dix lignes pour faire les binômes, et vendredi tu compareras.

C'est bon quand ta ligne de résumé est dans le canal Teams.

Ouvre le repo partagé dans le devcontainer (VS Code : Reopen in Container). Lance chaque ligne dans son terminal.

Toujours cassé à 10h15 ? Mets-toi en binôme avec un voisin pour le bloc git de 10h30, et répare le tien avec le formateur pendant le déjeuner. Toujours bloqué ? Demande dans le canal Teams.
